# 次セッション継続用メモ（テンプレート）

このファイルは、`/session-cont` 実行時に「現状を次セッションに引き継ぐ」目的で書く `TODO_NEXT_SESSION.md` の雛形である。本ファイル自体はテンプレートで、実際の `TODO_NEXT_SESSION.md` はプロジェクトルートに置く。

## 使い方

- `TODO_NEXT_SESSION.md` を新規作成または更新する際、本テンプレートの節構成と記述粒度に倣う。
- 各節の指針は `<!-- ... -->` で記す。記述時はコメントを削除し、本文に置き換える。
- 節を増減してよいのは、本プロジェクトのその時点の事情で必要なときのみ。粒度はテンプレートに揃える。
- 「完了した作業」と「次の作業」を混在させない。確定したものは前者、未着手・継続中のものは後者。
