# 隔離証拠 (取得プロトコル側) — 2026-05-13

## 隔離日

2026-05-13

## 隔離した対象

`dual-reviewer-rebuild/experiments/protocols/` 配下に存在していた次の 5 サブディレクトリ。

- `intent-track-runs/`：意図段階の取得バッチ群。
- `spec-track-runs/`：仕様段階の取得バッチ群。
- `implementation-track-runs/`：実装段階の取得バッチ群。
- `heuristic_profiles/`：取得処理が発見を出力する根拠としていた規則ファイル群。
- `analysis_profiles/`：取得結果を分類するためのプロファイル群。

## 隔離した理由

取得処理が大規模言語モデルを実際には呼び出していなかったことが 2026-05-13 に判明した。具体的には次のとおり。

- 取得処理（Ruby のランナー）には、Anthropic、OpenAI、Claude などの API 呼び出しが一切存在しなかった。
- 発見はすべて `heuristic_profiles/` 配下の規則ファイルの規則を入力文書に機械的に照合した結果として出力されていた。
- そのため、各バッチで観測された発見数は、レビュー処理の振る舞いではなく、規則ファイルの設計に決定論的に依存していた。

`heuristic_profiles/` 自体は汚染の根本原因にあたるが、再設計の参考として一定の役割があるため、削除でなく隔離扱いとする。

## 取り扱い方針

- 本ディレクトリ配下の取得結果は、論文や評価文書から引用しない。
- 再取得（実 LLM 呼び出しに切り替え、規則ファイルへの依存をなくす）が完了するまでは保留扱い。
- 計画系の見直しと取得処理の再設計が終わった段階で、再取得結果のみを新しい場所に配置する。
