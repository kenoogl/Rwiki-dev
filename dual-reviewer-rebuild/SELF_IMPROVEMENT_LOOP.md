# SELF_IMPROVEMENT_LOOP

## Inputs

- review logs
- override patterns
- false positive and false negative observations
- downstream rework signals

## Loop

1. detect recurring failure or bias pattern
2. write proposal artifact
3. backtest or replay
4. approve or reject update
5. version the accepted change

## Constraints

- no ad-hoc permanent repo-external memory patches
- no unverified prompt growth
