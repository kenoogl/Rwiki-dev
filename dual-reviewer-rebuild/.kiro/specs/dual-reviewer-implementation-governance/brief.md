# Brief

`dual-reviewer-implementation-governance` は、`dual-reviewer-rebuild` 全体の
implementation completion rule を定義する cross-cutting spec である。

この spec は feature artifact そのものではなく、

- implementation 完了後に何を review するか
- 何を evidence として残すか
- どの metric で conformance review の有効性を測るか

を repo-contained process artifact として固定する。
